# Quirky Holidays

A free, plain HTML/CSS/JS offline calendar. Open https://my-recipe-box-6128.github.io/quirky-holidays/ . No runtime dependencies, accounts or analytics.

## Data
365 month/day keys; 3 fixed-date observances each (1,095 entries). Names and annual date rules checked against individual Days Of The Year pages on November 26, 2026. Each entry includes its source URL. Original short descriptions. Selected dates cross-checked against https://www.timeanddate.com/holidays/fun/ . A curated selection, not an exhaustive list. Floating observances are omitted. February 29 offers a friendly leap-day note; only the 365 regular calendar dates have holiday entries.

## Install
Open once online until Ready for offline days appears. iPhone browser Share > Add to Home Screen. Site data may be cleared by the phone. Share uses the native share sheet, with clipboard/manual-copy fallback.

## Maintenance
Edit holidays.json for content; bump the cache version in sw.js whenever any file changes. GitHub Pages: main branch, root.
